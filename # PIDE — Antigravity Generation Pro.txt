```

      - On exception → (1.0, {}) fail-secure
      - Full type hints + docstring
```

## STEP 7 — layers/layer4_scoring.py + pipeline.py (L4 + Orchestrator)

```
Using the master context, generate TWO files:

FILE 1: layers/layer4_scoring.py
- Class `RiskEngine` with:
    __init__(self, config_path: str = "config/scoring.yaml") -> None
      - Loads scoring.yaml (hot-reloadable — re-read on each score() call 
        OR load once with a reload() method, your choice, document it)
    
    score(self, l1: float, l2: float, l3: float) -> tuple[float, str]
      - Returns (risk_score: float, decision: str)
      - risk = w1*l1 + w2*l2 + w3*l3
      - decision = "BLOCK" | "SANITISE" | "ALLOW" based on thresholds
      - On exception → (1.0, "BLOCK") fail-secure
    
    write_audit_log(self, prompt: str, l1: float, l2: float, l3: float,
                    risk: float, decision: str, trigger: str,
                    l2_exemplars: list[str], l3_signals: dict,
                    latency_ms: float) -> None
      - Writes ONE JSON line to logs/audit.jsonl
      - Logs prompt_hash (SHA-256 of prompt, NOT the raw prompt)
      - Includes: timestamp, all scores, weights, risk, decision, trigger, 
                  l2_exemplars, l3_signals, latency_ms
      - Creates logs/ directory if missing

FILE 2: pipeline.py
- Function `detect(prompt: str, layer1, layer2, layer3, layer4) -> dict`
  Complete orchestration:
  1. Start latency timer
  2. L1: if score==1.0 → short-circuit, skip L2+L3, set trigger="L1:pattern_id"
  3. If not short-circuit: run L2 and L3 (can use threading for parallelism)
  4. L4: compute risk + decision
  5. Write audit log
  6. Stop timer
  7. Return: {decision, risk_score, l1_score, l2_score, l3_score, 
              trigger, l2_exemplars, l3_signals, latency_ms}
  - Each layer wrapped in try/except → 1.0 on error, log error, continue
  - Full type hints, docstring listing return schema

- Function `load_pipeline(config_dir: str = "config") -> tuple`
  Returns (layer1, layer2, layer3, layer4) fully initialised

- If __name__ == "__main__": end-to-end test with 4 prompts covering all 3 decisions
```
